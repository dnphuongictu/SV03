# Papers - ViDroidCall Studio

Thu muc nay chua cac bai bao nen ve Android agent, dataset goi lenh, mobile LLM va quantization.

## Thu tu doc

1. `02_DroidCall_dataset.pdf`
   - Bai/dataset goc ve Android function calling.
   - Doc de nam format cau lenh, schema va metric danh gia.

2. `03_AutoDroid_android_agent.pdf`
   - Nen tang ve Android task automation bang LLM.

3. `06_A3_android_agent_arena.pdf`
   - Benchmark Android GUI/mobile agents.

4. `04_PhoneLM_mobile_llm.pdf`
   - Nen tang small language model cho dien thoai.

5. `07_MNN_LLM_mobile_inference.pdf`
   - Runtime/inference engine cho LLM tren thiet bi di dong.

6. `05_Quantization_tradeoffs_mobile_llm.pdf`
   - Trade-off giua model size, task difficulty, latency va accuracy.

7. `08_AWQ_quantization.pdf`
   - Nen tang quantization de hieu model nen 4-bit.
